# SceneMixer 大陆站一比一复刻功能基线

核查日期：2026-11-06。范围是 [scenemixer.cn](https://scenemixer.cn/) 整站，而非 `#world` 一节。依据为 Orca 浏览器中的实际公开页面；登录后的生成、支付、空间服务端算法没有实际执行。因此下文区分「页面可见」「官网描述」「未验收」。

| 域 | 要复刻的用户可见能力 | 一手证据与边界 |
| --- | --- | --- |
| 获客与注册 | 首页、行业/场景落地页、指南、样片库、定价、帮助；手机验证码登录，推荐码与邀请入口 | [首页](https://scenemixer.cn/)、[样片](https://scenemixer.cn/drama/)、[帮助](https://scenemixer.cn/help/)、[定价](https://scenemixer.cn/pricing/)、[登录](https://scenemixer.cn/login) 实见；邀请页登录后才可见 |
| 四种创作入口 | 上传小说/剧本；一句话 AI 创作；商品照片广告；参考视频复刻，进入同一项目编辑器 | [帮助中心](https://scenemixer.cn/help/)描述；未登录实际创建项目 |
| 剧本与资产 | TXT/DOCX/Markdown、长篇拆集；角色/场景/道具设定；上传替换、角色音色、跨项目复用与状态变体 | [首页](https://scenemixer.cn/)、[帮助中心](https://scenemixer.cn/help/)描述；[样片项目](https://scenemixer.cn/showcase/815/episode/2470)可见角色、场景、道具资产栏 |
| 世界与空间一致性 | 每场戏先建立同一片场；360° 环视、家具位置与尺寸、人物位置；从共享空间解算全景、过肩、反打、特写机位，跨镜头/跨集复用 | [首页世界段](https://scenemixer.cn/#world)可见交互展示及文字主张；无法由网页证明真实服务端实现或「自研物理视频基础模型」 |
| 分镜与视频 | 每集分镜；逐片段镜头脚本、时长、模型档位、带对白视频；修改画面/台词、裁剪、只重生成片段、历史版本；任务并发与失败状态 | [样片项目](https://scenemixer.cn/showcase/815/episode/2470)实见脚本、视频、10 段 93 秒时间轴与编辑控件，但样片编辑控件禁用；[帮助中心](https://scenemixer.cn/help/)描述实际编辑、版本与任务语义 |
| 成片与交付 | 单集合成、配乐、字幕/SRT、横竖屏、多语言台词、封面、播放、分享、下载 | [样片项目](https://scenemixer.cn/showcase/815/episode/2470)实见成片播放/分享/下载；[首页](https://scenemixer.cn/)与[帮助中心](https://scenemixer.cn/help/)描述其他能力 |
| 商业与账务 | 免费设定图/首集分镜/短预览；积分按字数、图片、视频秒数、合成秒数计价；提交前报价；任务中冻结、交付消费、失败退款；充值包；月/季/年会员、并发/项目/存储额度；支付宝/微信 | [定价](https://scenemixer.cn/pricing/)、[会员](https://scenemixer.cn/membership)、[帮助中心](https://scenemixer.cn/help/)显示规则；未测试真实支付回调或账本一致性 |
| 运营与信任 | 内容审核、AI 生成标识、用户支持/AI 问答/反馈、隐私与条款、订单与退款规则 | [帮助中心](https://scenemixer.cn/help/)、[首页](https://scenemixer.cn/)与其页脚入口描述；未登录内部流程未验收 |

一比一的验收单位是整个用户旅程：陌生访客到站 → 注册/免费体验 → 创作四入口之一 → 建角色场景与世界 → 多集分镜 → 逐段视频与精修 → 成片/字幕/分享 → 充值或会员 → 账务/失败退款/客服。候选若只有普通参考图一致性，不能记为「世界与空间一致性」已满足；若只有会员 UI，不能记为支付与账务闭环已满足；营销页数量不以复制文案计算，还需复刻可维护的页面生成与内容运营能力。
