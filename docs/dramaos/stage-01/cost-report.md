# Stage 01 资源与成本

此轮没有购买硬件、调用付费 API、运行 GPU 推理或下载模型权重；直接付费服务成本为 ¥0。下面是本机单次运行观察值，不含人力、电力、设备折旧，也不是容量基准。

| 输入 | CLI 耗时 | 最大单个子进程 RSS | 输出大小 | 模型调用 |
|---|---:|---:|---:|---|
| 3 秒合成硬切 | 0.289 秒 | 37,634,048 字节 | 约 5.3 KB | 无 |
| 60.47 秒现有成片 | 3.773 秒 | 203,669,504 字节 | 约 3.2 MB | 无 |

`run.json` 使用 `RUSAGE_CHILDREN.ru_maxrss` 记录观察到的最大**单个**子进程 RSS，macOS 原值为字节，Linux 会从 KB 换算到字节。该值不是整个进程树同时占用内存之和，也不能代表 GPU 峰值。Stage 01 没有执行 GPU 工作，因此 GPU 用量为未测量而非 0 峰值。
