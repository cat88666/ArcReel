# ArcReel
## AI 短剧运营操作手册

从小说、成品剧本到可交付短剧

适用人员：内容运营、编导、素材审核、视频制作与交付人员。

适用环境：管理员已经部署并配置好 ArcReel，运营通过浏览器使用。本文以「剧情演绎」项目为主线。

版本：1.0 · 编制日期：2026 年 10 月 12 日

> 使用前请向管理员领取平台地址和登录账号。模型、费用和生成时长以团队当前配置为准。

制作主线

原文与剧本 → 分集与内容确认 → 角色与场景 → 分镜与样片 → 批量制作 → 剪辑与交付

本文中的对话示例是可复制的操作建议，不是平台内置按钮。界面标签用「」标出。每个阶段先检查结果，再继续下一阶段。

## 一集短剧的六个检查点

1. 原文与分集正确：没有漏章、重复或断在错误位置。
2. 脚本正确：剧情、说话人、台词、场景、镜头时长已审核。
3. 资产正确：主要角色造型、场景和关键道具已确认。
4. 样片通过：人物、动作、声音与镜头衔接达到团队要求。
5. 本集齐全：应交付片段已完成，失败项与过期项已处理。
6. 成片通过：从头到尾播放最终文件，完成画面、声音和字幕检查。

# 01 · 登录与认识工作台

## 开始前准备

向管理员确认平台地址、用户名、密码，以及团队已经验证可用的图像模型和视频模型。另备好小说或剧本、目标画面比例、每集时长要求、人物设定及参考图。

1. 用电脑浏览器打开管理员提供的平台地址。
2. 在登录页填写「用户名」和「密码」，点击「登录」。
3. 进入项目列表。已有项目直接打开；首次制作点击「新建项目」。
4. 如需切换界面语言，进入「全局设置」→「通用」→「界面语言」，选择中文。切换立即生效。

## 工作台各区域的用途

| 区域或入口 | 日常操作 |
| --- | --- |
| 项目概览 | 看制作进度、项目设定、缺少的产物与费用概况。 |
| 分集、具体集页面 | 整理原文、规划脚本、制作分镜和视频；进入剪辑。 |
| 角色集、场景库、道具库 | 建立并审核反复使用的形象与环境。 |
| 右侧 ArcReel Agent | 下达带范围的制作指令、检查缺项、调整剪辑。 |
| 顶栏「使用记录」入口 | 查看进行中与已结束任务、错误及参考费用。 |
| 顶栏「导出项目」 | 下载项目 ZIP 归档，不是下载 MP4 成片。 |

## 第一次操作如何确认环境可用

在 Agent 输入：「检查当前项目的制作条件和下一步缺项，先不要生成图片或视频。」如果提示模型未配置、权限不足或连接失败，将提示交给管理员处理。

> Agent 能回复，不代表图片和视频模型也可用。运营沿用团队已验证的配置；需要更换模型时，先让管理员确认能力与费用。

# 02 · 创建 AI 短剧项目

## 操作步骤

1. 在项目列表点击「新建项目」。
2. 输入「项目标题」。建议采用「作品名／季或批次」便于查找，例如「雨夜来信 第一季」。
3. 「创作类型」选择「剧情演绎」，用于角色表演、对白与镜头叙事。
4. 选择「生成方式」：分镜图生视频或参考生视频，区别见下表。
5. 在「基础信息」设置画面比例，按照团队要求选择竖屏或横屏，点击「下一步」。
6. 在「生成设置」确认团队指定的模型和制作参数，再点击「下一步」。单集目标时长是规划的软目标；这里的语速用于估算，不改变实际配音速度。
7. 在「风格」选择整部短剧的视觉风格，检查后点击「创建项目」，再开始录入小说或剧本。

| 生成方式 | 制作路径与选择依据 |
| --- | --- |
| 分镜图生视频 | 先生成并审核每个镜头的分镜图，再生成视频。适合需要先锁定构图、人物位置和场景的制作。 |
| 参考生视频 | 用正文提示词与被引用的资产图生成视频，不先制作每镜分镜图。需要团队已验证支持参考输入的视频模型。 |

## 创建前必须确认

- 创作类型和生成方式创建后不能更改。选错时，新建正确类型的项目，再录入内容。
- 小说和成品剧本是「源文件类型」，不是上面的生成方式。两者都可以制作剧情演绎短剧。
- 多宫格是分镜图生视频中的出图选项，不是第三种视频生成方式；相关步骤见第 9 页。
- 项目设置中的模型选择会影响这个项目。不要假定全局默认模型变更后，已有项目一定随之改变。

> 验收结果：项目标题、剧情演绎类型、画面比例、生成方式和风格均与制作要求一致。

# 03 · 上传小说或成品剧本

## 上传前整理

小说按章节整理，删去与故事无关的目录广告和重复内容。成品剧本尽量清楚区分场次、人物名、台词、动作与画外音；必须保留的台词和剧情先做好标记。

1. 在项目欢迎区拖入文件，或点击「上传原文」「选择文件」。
2. 选择源文件类型：小说选择「小说」，已经写好的剧本选择「剧本」。
3. 选择录入方式：未分集的内容用「整本源文」；已按集整理的内容用「逐集原文」。
4. 上传多个文件时，检查列表顺序，用拖动或上下箭头调整。
5. 确认上传后，打开抽取的文本，检查开头、结尾、人物名和特殊符号。

| 录入方式 | 实际结果 |
| --- | --- |
| 整本源文 | 一个或多个文件按界面列表顺序接成整本内容，随后再分集。文件名本身不决定拼接顺序。 |
| 逐集原文 | 每个文件对应一集，按列表顺序追加到现有集目录末尾。 |

## 文件格式与异常

- 支持 TXT、MD、DOCX、EPUB 和 PDF。
- 扫描版 PDF 没有可提取文字时，先由内容提供方做文字识别；旧式 DOC 先转为 DOCX。
- 乱码、缺字或顺序混乱时，先修正源文件，再继续规划。
- 多文件上传中途失败时，已成功的文件可能已经保存。核对列表后只补传剩余文件，避免重复内容。

> 剧本项目建议给 Agent 明确约束：「台词和画外音逐字保留，不自行补写人物对白；需要删改时先列建议，等待确认。」上传完成不等于内容已经审核。

# 04 · 故事设定与分集

## 先确定整部短剧的共同设定

检查梗概、类型、主题、世界观，以及核心人物关系、年代和地点。可使用「从原文生成」辅助整理，然后人工核对。已有内容时，「从原文重新生成」会整体替换相关设定，操作前保留需要的文字。

## 未分集的小说

1. 进入「分集」，查看整本源文的顺序和完整性。
2. 点击「AI 规划分集」，在弹层的「附加指令」里说明每集目标、转折与结尾悬念，再点击弹层内的「AI 规划分集」提交；也可「交给 Agent」。
3. 逐集核对开头和结尾，确保人物行动有因果关系，没有把一句话或关键冲突切断。
4. 检查是否出现「未切分的原文」。已经规划到结尾，不代表中间没有遗漏。
5. 后续继续制作未处理的部分时，使用「AI 规划剩余内容」。

## 已分集的成品剧本

使用逐集原文后，先核对集数和排序，保持原剧本的场次与人物对白。若内容已经按集整理，不要无意中让 Agent 重新改编整部故事。

## 建议复制的指令

> 只处理第 1 集。先核对本集原文和故事设定，列出人物、场景、关键道具及剧情冲突。保留既有台词与人物关系；先完成脚本规划，等待我审核，不生成图片或视频。

## 完成条件

集目录正确；每集内容范围清晰；无重复和遗漏；本集的剧情目标、角色出场与结尾位置已经确认。

「停止规划」会等待当前段结束，已经规划好的集会保留。停止后先检查现有结果，再决定是否继续。

# 05 · 脚本规划与内容确认

1. 打开要制作的一集，点击「AI 规划脚本」，填写附加要求后点击「AI 规划」；也可「交给 Agent」。
2. 等待规划完成，进入内容确认，按下方清单逐个镜头检查。
3. 审核「本集新增资产」：确认每项应登记为新资产、归入已有资产、登记为衍生，还是不登记。
4. 修正台词、说话人、时长和引用等问题。确认时，新资产随正式脚本一起登记。
5. 点击「确认并继续」，再检查正式脚本是否已就绪。

| 检查项 | 运营应确认什么 |
| --- | --- |
| 剧情 | 事件顺序、转折和人物动机正确，没有擅自改写重要情节。 |
| 发声 | 台词与画外音区分清楚；说话人正确；动作说明不当作台词。 |
| 镜头 | 一镜的动作能够在所选时长内表达，人物位置和场景切换明确。 |
| 时长 | 使用当前视频模型可用的档位；红色或失效时长必须先修正。 |
| 资产 | 同一角色没有重复登记；角色、场景和道具引用都能对应真实资产。 |

## 确认之后如何修改

已确认的规划页为只读。局部修改使用「去时间线修改」；整集重新规划后，需要再次确认。「确认并覆盖正式脚本」是整体重建，不是只更新几句话。

## 出现待修复草稿

先保存手工修改，再用「保存并校验」查看问题；需要时使用「AI 修复」或「交给 Agent 修复」。问题清零并采用正式内容后再继续。不要带着未保存修改让 Agent 同时编辑同一份内容。

> 验收结果：正式脚本已就绪，内容审核通过，时长和资产引用没有阻断问题。参考生视频的引用写在正文中，检查方法见第 10 页。

# 06 · 建立角色、场景与道具

## 先做好反复使用的资产

角色、场景和道具的「定义」与「图片」是两回事。资产已登记，不代表已有可用于生成的参考图。

1. 进入「角色集」，检查主角及常驻角色的名称、别名与描述。
2. 固定年龄段、发型、五官特征、体型、常驻服装及声音描述；同一个人用同一项资产。
3. 生成资产图，或使用「上传资产图」上传团队确认的图片。
4. 进入「场景库」「道具库」，完成本集需要的环境和关键道具图。
5. 逐张审核合格后，再开始分镜和视频；可从「生成本集待生成的资产」检查批量列表并点击「开始生成」。

| 资产 | 审核重点 |
| --- | --- |
| 角色 | 外貌和年龄正确；服装符合年代；脸部、手部无明显异常；造型可跨镜头重复使用。 |
| 场景 | 空间结构、光线、年代、色调一致；用于纯环境参考时避免混入无关人物。 |
| 道具 | 形状、颜色、材质正确；需要特写的关键道具清晰可辨。 |

## 换装、受伤或变身

同一角色需要稳定的新外观时，用「新增衍生」描述相对本体的变化。先有本体资产图，再生成衍生图；在对应分镜里引用正确造型。

## 不满意时

先修改具体描述，再重做对应资产，或在资产「版本历史」预览并还原合格版本。资产图改动后，下游画面可能变为过期，但不会自动重做，处理方式见第 15 页。

> 验收结果：本集所有被引用资产都有合格图片，同一人物没有被误建成多个互不关联的角色。

# 07 · 分镜图生视频：先做分镜图

本页适用于创建时选择「分镜图生视频」的项目。参考生视频项目直接看下一页。

1. 确认正式脚本和引用资产已就绪。若缺少提示词，可按制作状态指引使用「AI 编写」，补齐未编写内容。
2. 在目标集的分镜制作界面，先选择少量代表性镜头：主角近景、多人同框、主要场景各覆盖一种。
3. 检查该镜头的角色、场景、道具引用以及分镜图描述。
4. 生成单镜分镜图，放大查看脸部、手部、服装、站位、景别和画面比例。
5. 将问题改到具体镜头或资产描述中，再重新生成问题镜头。
6. 样图合格后，点击「补齐分镜图」完成剩余缺图镜头。

## 分镜图审核清单

- 同一角色跨镜头相貌和服装一致，没有无故换人。
- 对话人物的左右关系清楚，视线方向合理。
- 背景符合场景设定，关键道具没有丢失或变形。
- 画面具备后续动作空间，不把人物肢体裁掉或挤出画面。
- 没有不需要的文字、水印或误生成的字幕。

## 使用多宫格时

进入「多宫格分镜图」视图 → 生成多宫格分镜或「补齐联合图」→ 审阅联合图 →「切分落格」。只有联合图，并不等于每个镜头已有分镜图。

切分会替换该组仍在剧本中的分镜图，旧图保留在版本历史中。组内顺序调整后，旧联合图可能不再匹配；单个缺图也可单独生成，无需盲目重做整组。

> 验收结果：准备生成视频的每个镜头都有合格分镜图。图片审核通过后，才进入视频生成。

# 08 · 参考生视频：核对正文和引用

本页适用于创建时选择「参考生视频」的项目。这条路线不先制作每镜分镜图，但仍需要被引用资产的图片。

1. 确认项目使用团队验证过的参考生视频模型。
2. 打开本集的视频单元，逐项检查正文中的角色、场景与道具。
3. 核对正文中的资产引用，例如 `@[林夏]`，名称应对应项目中已登记的资产。
4. 确认每个被引用资产都有可用图片；未登记或缺图的引用先修复。
5. 检查视频单元时长是否在当前模型可用档位内。
6. 先生成一个代表性单元，核对人物一致性、动作、对白和实际时长，再批量补齐。

## 怎样写清一个视频单元

描述清楚地点、人物、主要动作、镜头变化和发声内容。不要只写情绪形容词，也不要在一个短片段里堆入多个地点或多次复杂转场。

建议给 Agent 的修改要求：

> 保留这个单元的剧情与台词，检查所有资产引用。明确谁在说话、谁只做动作；动作和镜头说明不要写成发声内容。只修正本单元，完成后等待我确认。

## 常见阻断

| 页面提示 | 处理方法 |
| --- | --- |
| 未登记的引用 | 使用已存在的资产名称，或先按内容审核结果登记资产。 |
| 引用的资产缺图 | 先补齐对应资产图，再返回该单元。 |
| 声明引用与可用参考图不一致 | 修复引用及图片，不要反复点生成。 |
| 时长档位未知或已失效 | 请管理员核对模型能力和项目配置，再选择可用时长。 |

> 没有引用场景时，地点可能由模型自由决定。需要固定环境的短剧镜头，应明确引用正确场景并检查生成结果。

# 09 · 先生成少量视频样片

## 样片的目的

验证当前人物、提示词、模型和时长组合是否能达到要求。建议先选择 2–4 个代表性镜头，覆盖对白、动作和场景衔接；这个数量是操作建议，不是平台限制。

1. 打开样片镜头或视频单元，确认没有未保存修改。
2. 分镜图生视频先确认分镜图；参考生视频先确认引用及资产图。
3. 检查视频描述中的动作、镜头运动、台词和说话人。
4. 点击「生成视频」。如出现时长档位确认，检查时长及费用后再确认。
5. 到「使用记录」查看任务状态，完成后回到镜头播放完整片段。
6. 记录问题所在秒数和现象；修改具体原因后，只重做有问题的镜头。

## 必须播放检查

| 项目 | 合格判断 |
| --- | --- |
| 人物 | 没有明显换脸、肢体异常或服装突变。 |
| 动作 | 动作与剧情一致；没有无意义循环、突然瞬移或方向反转。 |
| 对白 | 说话人正确，内容完整，口型与声音达到交付要求。 |
| 衔接 | 片段开头、结尾可以与前后镜头连接，关键动作不被截断。 |
| 时长 | 实际片段长度可用于剪辑；档位变化没有破坏叙事。 |

系统按模型支持的档位交付，不保证自动裁剪为最初请求的时长。若需要精确节奏，在剪辑阶段调整。

> 样片不通过时，先修正问题再扩大生成。不要因为任务显示成功，就把画面和声音视为审核通过。

# 10 · 对白、画外音与声音一致性

## 剧情演绎的声音检查

视频模型的原生人声、角色参考音频、独立旁白 TTS 是不同能力。当前 Web 的独立旁白 TTS 面向「旁白/解说」项目，不要在剧情演绎项目里寻找同样的批量旁白入口。

1. 在脚本中检查每句发声的类型：人物开口说话用台词，不出镜的叙述按画外音处理。
2. 确认每句台词的说话人，避免多人镜头中声音分配错误。
3. 将动作、表情和镜头说明与发声内容分开。
4. 生成后戴耳机听完整片段，核对漏句、加词、读错人名、动作被朗读和异常噪声。
5. 将相邻片段连着听，检查同一角色的音色、音量与情绪是否连贯。

如果页面提示同一视频单元同时包含角色台词和旁白，应先拆分或重新规划，让该单元由一种发声主体负责，再生成视频。

## 角色声音如何约束

默认可以用角色声音描述约束视频模型，但跨片段只能追求近似，不能保证完全相同。需要直接复用原声时，先让管理员确认以下条件全部满足：

- 项目使用参考生视频。
- 所选视频模型支持参考音频。
- 项目「角色声音绑定方式」设为「参考音频」。
- 每个有台词的角色已配置参考音频。

分镜图生视频不支持这条参考音频绑定路径。若团队选择后期配音，按团队剪辑流程录制或制作声音，并在最终剪辑中完成同步。

> 出现“动作说明被念出来”时，先定位具体片段、台词和提示词，修正发声表达并做单镜验证。不要整集反复重做，也不要认为添加字幕可以解决原音轨问题。

# 11 · 批量补齐一集视频

## 开始批量前

确认脚本和资产已审核，样片已通过，当前集数无误。与团队约定本批次范围和预算；不要在批量生成过程中同时大幅修改剧本或角色设定。

1. 打开目标集，检查分镜图或参考资产是否准备齐全。
2. 分镜图生视频如有缺图，先「补齐分镜图」，审核完成后再继续。
3. 点击「补齐视频」。若出现档位调整提示，核对后选择「按这些档位生成」等当前显示的确认操作。
4. 进入「使用记录」查看任务，不要因为页面暂时未更新就重复提交。
5. 任务完成后逐镜检查。部分失败时，只处理失败原因和缺失项。
6. 记录已通过镜头、待重做镜头及原因，交给下一班或剪辑人员。

## 「补齐」与「重新生成」的区别

| 操作 | 用途 |
| --- | --- |
| 补齐分镜图／补齐视频 | 默认补缺失项；当前和过期产物都会保留。 |
| 对指定镜头重新生成 | 用于已有结果需要更新、质量不合格或输入已改的情况，通常会新增生成调用。 |

## 对 Agent 明确范围

> 第 1 集的脚本、资产和样片已审核。只补齐本集缺失的视频，不重做已有结果，不处理其他集。完成后列出失败项和仍需人工审核的镜头。

> 验收结果：所有应交付镜头均有可用视频；每个视频经过人工检查。存在过期标记的镜头，需要明确决定继续使用还是重新生成，不能仅凭“都有文件”判定完成。

# 12 · 任务状态与失败恢复

从顶栏费用或任务数量入口打开「使用记录」，查看「进行中」「最近已结束」；点击「查看全部记录」可按项目、供应商、模型、媒体类型和状态筛选。

| 状态或情况 | 应当如何操作 |
| --- | --- |
| 排队中 | 等待可用执行名额。确需停止时取消排队任务，并看清是否连带取消下游排队任务。 |
| 运行中 | 等待结果；运行任务不能取消，已发出的调用会继续完成。 |
| 成功 | 返回镜头检查实际图片或视频，成功只代表任务完成。 |
| 失败 | 展开错误，判断是输入、模型、权限、限流还是下载问题，再处理。 |
| 部分数据加载失败 | 点击「刷新」，先获取最新状态，避免重复提交。 |
| 视频下载失败且有「重试下载」 | 优先点击它，取回原任务已有产物，不重新提交生成。 |

## 普通失败的处理顺序

1. 记录项目、集数、镜头编号和失败时间。
2. 展开并保存完整错误信息；不要只截取“失败”两个字。
3. 输入或引用错误先在相应页面修正；账号、模型或网络错误交给管理员。
4. 确认没有仍在运行的同一任务，再回到对应资产或镜头入口重新生成。

任务面板没有适用于所有任务的统一重试按钮。「重试下载」只用于已有视频取回失败；它不会重新生成或增加一笔生成计费。

## 服务重启或超时后

先检查当前任务和已有结果；需要时请管理员核对供应商侧任务。部分可恢复任务会继续轮询，其他任务可能失败，不要假定全部已停止或全部会自动恢复。

> 费用记录用于参考和核算辅助；供应商实际账单仍应由管理员核对。连续重复提交会扩大成本，不能代替排错。

# 13 · 返工、过期标记与版本

## 先理解产物状态

| 状态 | 含义和处理 |
| --- | --- |
| 当前 | 产物与当前输入和所选版本一致，仍需检查内容质量。 |
| 过期 | 文件仍在且可预览或导出，但相关输入变过；审核后决定保留或重新生成。 |
| 缺失 | 没有可用正式产物，使用对应补齐入口生成。 |
| 阻塞 | 引用或产物记录等存在问题，先修复；系统不会自动把它当缺失项重做。 |

## 单个镜头返工

1. 写清镜头编号、问题秒数和预期结果。
2. 找到责任位置：角色设定、资产图、分镜图、视频提示词或声音。
3. 修改并保存，检查是否影响同一角色的其他镜头。
4. 只重做需要更新的镜头；播放新结果，与旧版比较。
5. 确定使用哪个版本，再检查剪辑时间线和导出是否需要刷新。

## 切换素材旧版本

在分镜图片、视频等区域打开「版本」→「历史版本」，点击版本号预览，选中合格版本后点击「切换到此版本」。生成或编辑进行中不能切换，请等待完成。

资产画廊的入口可能显示为「版本历史」和「还原到此版本」，按该区域实际按钮操作。版本切换针对素材，不等于整个项目一键回滚。

## 避免扩大返工

更换角色参考图可能让关联分镜和视频过期；改分镜图不会自动重新生成视频；改剪辑后旧成片也不会自动成为最新版。逐层检查需要更新的范围。

> 不要通过删除项目、删除资产或整集覆盖来修复单镜问题。资产删除无法撤销，还可能使已有脚本引用失效。

# 14 · 建立剪辑时间线

视频生成完成后，还需要建立剪辑时间线。成片的顺序、取段和声音安排由这条时间线决定。

1. 进入要交付的一集，切换顶部「剪辑」视图。
2. 没有时间线时，选择「交给 Agent 剪辑」或「新建剪辑时间线」。至少需要已有一个可用视频。
3. 选中要使用的时间线，核对镜头排列、实际时长和缺失项。
4. 需要调整时，在 Agent 对话中明确集数、时间线和要改的片段。
5. 检查问题列表；缺少视频等阻断问题必须先处理。

## 建议复制的剪辑指令

> 为第 1 集按正式脚本建立一条剪辑时间线。保留已审核的素材版本，检查对白是否完整、镜头顺序是否正确，列出缺失视频与声音问题。先完成时间线供我审核，不直接渲染成片。

## 背景音乐

在 BGM 轨名称旁的上传入口上传 MP3、WAV 或 M4A，文件不超过 100 MB。上传后让 Agent 将音乐放入时间线，并说明开始位置与情绪；仅上传文件，不代表时间线已经使用它。

BGM 属于项目，各集可使用。几乎无声的音频无法上传；同一时刻只使用一首 BGM。超出时间线末尾的部分会被截掉并淡出。目前页面不支持删除已上传 BGM。

## 时间线审核

- 无黑场、遗漏或重复镜头；对话顺序正确。
- 剪辑没有截断人物台词或关键动作。
- 音乐不遮盖对白，片头片尾没有突兀声音。
- 需要的字幕与画面内容一致；剧情演绎的字幕来自台词和画外音。

> 「出片」不会代替建立时间线。先确认选中了正确集和正确时间线，再进入导出。

# 15 · 渲染并下载 MP4 成片

1. 在目标集的「剪辑」视图中，选中已审核的时间线。
2. 点击「出片」，确认对话框标题中的时间线名称。
3. 选择「成片」。
4. 检查「烧入字幕」选项。默认勾选；烧入后字幕成为画面的一部分，播放时不能关闭。
5. 没有成片或成片已过期时，点击渲染，等待对话框进度完成。
6. 点击下载，保存到团队交付目录。
7. 用本地播放器从头到尾检查实际下载文件，而不只看网页预览。

| 对话框状态 | 操作 |
| --- | --- |
| 已是最新 | 可直接下载对应版本。 |
| 已落后于剪辑时间线 | 说明时间线或素材有更新；确认后重新渲染再下载。旧文件仍可能可以下载。 |
| 尚未生成 | 先渲染，再下载。 |

## 出片按钮不可用

悬停查看原因，点击旁边「查看问题」进入问题列表。缺失视频先补齐；字幕不支持字符等提示也应检查。剧情演绎项目不需要寻找 TTS 项目的「带旁白／不带旁白」切换入口。

## 下载后命名建议

例如：作品名_E01_竖屏_字幕版_v01.mp4。修订后递增版本，并在交接记录中注明变化。此命名是团队管理建议，不是平台强制要求。

> 验收结果：文件可播放、画面比例正确、对白完整、字幕正确、音量正常，且确认下载的是当前审核通过版本。系统“生成成功”不等于已经发布，也不代表业务审核完成。

# 16 · 导出剪映草稿继续精剪

适用于需要在剪映桌面版继续调整节奏、字幕、声音或包装的交付。当前指南面向中国大陆桌面版剪映，不能据此保证 CapCut 兼容。

## 导出与下载

1. 在本机剪映「设置 → 草稿位置」找到真实草稿目录。
2. 回到 ArcReel 的目标集「剪辑」视图，选中需要的时间线。
3. 点击「出片」→ 选择「剪映草稿」。
4. 若尚未生成或已落后于时间线，点击「导出剪映草稿」并等待完成。
5. 下载时填写「草稿目录路径」，选择匹配本机的「剪映 6.0 及以上」或「剪映 5.x」。
6. 点击「下载」，取得 ZIP。路径和版本在下载时使用，换电脑时应重新填写并下载。

## 解压与打开

将 ZIP 解压到刚才确认的草稿目录。草稿文件夹应直接位于该目录下，不要多套一层同名文件夹。重启剪映，在草稿列表打开项目，检查素材是否齐全、时间线是否正确。

默认路径示例仅供定位，实际以剪映设置为准：

`macOS: /Users/<用户名>/Movies/JianyingPro/User Data/Projects/com.lveditor.draft`

`Windows: C:\Users\<用户名>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft`

## 找不到草稿或缺片段

先检查解压路径和文件夹层级，再核对剪映版本并重启。草稿只包含所选剪辑时间线里的片段，不会自动收集整集所有素材；缺片段先回 ArcReel 检查时间线。

> 草稿 ZIP 是可编辑工程，不是最终视频。交付前还需在剪映内检查并导出最终成片。

# 17 · 项目归档与多人交接

## 区分三种文件

| 文件 | 交给谁、用于什么 |
| --- | --- |
| MP4 成片 | 审核、发布人员；可直接播放。 |
| 剪映草稿 ZIP | 剪辑人员；在本机剪映继续编辑。 |
| 项目归档 ZIP | ArcReel 制作接手人员；保存项目数据和素材，支持项目导入。 |

## 导出项目归档

1. 在项目顶栏点击「导出项目」。
2. 在「选择导出范围」中选择「仅当前版本」或「全部数据」。
3. 仅交接当前采用素材时选择「仅当前版本」；需要保留完整历史时选择「全部数据」。
4. 点击「导出」下载 ZIP，与制作记录一起保存。

项目 ZIP 不等于全站备份，不能代替管理员对数据库、全局配置和凭据的备份。运营无需复制或传播平台密钥。

## 导入接手

在项目列表使用「导入 ZIP」。若项目 ID 冲突，优先选择「自动重命名导入」以保留现有项目。只有明确要替换现有项目时才选择覆盖，并先做好归档；覆盖不是合并。

## 交接记录至少写清

- 作品名、集数、负责人、交接时间和交付文件名。
- 当前使用的素材版本与剪辑时间线。
- 已审核镜头、待修镜头及具体问题。
- 尚在排队或运行的任务，以及是否需要接着处理。
- 本集是否已经交付，交付对象是谁。

> 多人协作时，避免同时编辑同一集或同一镜头。页面提示外部更新时，先保存需要保留的文字，再按提示处理，不要直接覆盖他人的修改。

# 18 · 常见问题速查

| 现象 | 先检查与处理 |
| --- | --- |
| 无法登录 | 核对地址和账号；把完整错误发给管理员，不自行修改服务配置。 |
| Agent 不继续制作 | 查看制作状态、内容确认和缺失资产；明确指定集数与下一步，不只反复发“继续”。 |
| 模型不存在或未配置 | 让管理员核对项目选中的模型是否可用、是否已激活对应配置。 |
| 401／403 | 交给管理员核对凭据和权限；重复生成不能修复授权。 |
| 429 | 让管理员检查额度、限流与并发；暂停新增任务，确认后再继续。 |
| 502、网络错误或超时 | 保存错误和时间；核对是否已有供应商任务或结果，避免重复计费。 |
| 内容确认无法通过 | 修正时长档位、未登记引用或待修复草稿，再确认。 |
| 视频生成按钮不可用 | 分镜图路线检查分镜图；参考路线检查资产图片、引用和模型能力。 |
| 改提示词后画面没变 | 修改不会自动重做；只对需要更新的镜头重新生成。 |
| 人物换脸或服装变化 | 核对引用的角色、衍生和参考图，先修一个镜头验证。 |
| 动作被念出、对白错人 | 检查台词／画外音及说话人，分离动作描述，再做单镜验证。 |
| 出片不可点或缺镜头 | 打开「查看问题」，核对剪辑时间线里的素材是否齐全。 |

## 交给管理员的报障内容

项目名、集数、镜头或视频单元编号、出错时间、操作入口、完整错误、是否重复提交、当前是否仍有任务运行，以及预期结果和实际结果。

必要时按管理员要求，从「关于」中的诊断日志区域下载诊断日志。发送前检查截图和附件，避免把密码、密钥或不相关的作品内容发给无关人员。

> 账号、供应商、网络或模型配置问题由管理员处理；运营负责提供能定位到具体任务的证据。

# 19 · 可复制的 Agent 操作指令

以下是建议措辞。发送前替换集数、镜头编号和作品要求；指令不会绕过系统条件，也不能保证模型生成质量。

## 小说改编前

> 只处理第 1 集。依据本集原文规划剧情演绎短剧，保留核心情节、人物关系和关键对白。先完成脚本规划，列出新增资产，停在内容确认，不生成图片或视频。

## 已有成品剧本

> 这份内容是已定稿剧本。逐字保留台词与画外音，不擅自增加对白或改变说话人。按场次拆成可制作镜头；如受时长限制，先提出拆分建议供我确认。

## 资产与分镜试产

> 只生成第 1 集缺失的资产图，保留已有合格版本。完成后等待我审核，不生成视频。

> 只处理第 1、2 个分镜，用于验证人物、服装、构图和画面风格。不要扩大到整集，完成后等待审核。

## 批量补齐

> 本集样片已经审核通过。只补齐第 1 集缺失视频，保留当前和过期的已有结果，不处理其他集。完成后报告缺失、失败和待审核项。

## 单镜返工
